# Beamer 讲义创建工作流

创建一份美观、内容严谨的 Beamer 演示文稿。适用于学术讲座、论文展示、研讨会报告。

**这是一个协作的、迭代的过程。作者推动愿景；Claude 是思维伙伴。**

---

## 约束条件（不可商议）

1. **首先阅读知识库** — 符号注册表、叙事弧、应用数据库
2. 每个新符号必须针对符号注册表进行检查
3. 动机优先于形式主义 — 没有例外
4. 每个定义后 2 张幻灯片内有具体例子
5. 每张幻灯片最多 2 个彩色框
6. 没有 `\pause` 或覆盖命令（检查项目规则）
7. 在主要概念转折处进行过渡幻灯片
8. 在整个过程中至少线索 1 个经验/实证应用
9. 针对参考文献验证所有引文
10. **分批工作 5-10 张幻灯片** — 分享反馈，不要大量倾倒

---

## 工作流

### 阶段 0：摄入和背景
- 读取知识库和创建指南
- 清点提供的材料（论文、幻灯片、代码、数据结果）
- 阅读前面讲义/章节的结构和结尾
- 阐述教学目标和受众，获得用户确认

### 阶段 1：材料分析（提供论文/代码时）
- 分块，提取关键思想和结果
- 将材料符号映射到项目符号
- 识别值得幻灯片的核心内容
- 提交摘要以获得批准

### 阶段 2：结构提案
- 提议大纲（引言 → 方法 → 结果 → 结论，或按主题划分）
- 列出所需的 TikZ 图表和 Python 图形
- 列出要引入的新符号
- **门控：用户在阶段 3 之前批准**

### 阶段 3：草稿幻灯片（迭代）
- 分批工作 5-10 张幻灯片
- 检查符号，应用创建模式
- 草稿期间的质量检查

### 阶段 4：图形和代码
- 遵循 Python 代码规范的分析脚本
- Beamer 源中的 TikZ 图表（单一真实来源）
- 保存图形为 PDF（用于 LaTeX 编译）

### 阶段 5：润饰和编译
- 完整的 3 遍编译（xelatex + bibtex + xelatex × 2）
- 运行 `/devils-advocate`
- 运行实质审查（`domain-reviewer`）
- 用新符号更新知识库

## 领域特定指导

### 金融/量化主题
- 优先展示：直觉图示 → 数学模型 → 数值示例
- 必须包含：假设清单、局限性说明
- 图表类型：时间序列、收益分布、参数敏感性、Payoff图

### 计算机科学主题
- 优先展示：问题陈述 → 算法 → 复杂度分析 → 实验
- 必须包含：算法伪代码、复杂度表格
- 图表类型：算法流程图、性能曲线、结构图

### 经济学/计量经济学主题
- 优先展示：实证问题 → 识别策略 → 结果 → 稳健性
- 必须包含：识别假设、潜在违反
- 图表类型：回归系数图、趋势图、分布对比
