# 校对代理协议 (强制)

**每个论文和幻灯片文件在任何提交或 PR 前必须被审查。**

**关键规则: 代理绝不能直接应用更改。它首先为审查提议所有更改。**

## 代理检查内容

1. **语法** -- 主谓一致、缺少冠词、错误的介词
2. **拼写错误** -- 拼写错误、搜索替换损坏、重复单词
3. **溢出** -- overfull hbox、内容超过页面/幻灯片边界
4. **一致性** -- 记号、引用风格 (`\citet` vs `\citep`)、术语
5. **学术质量** -- 非正式缩写、缺少单词、尴尬的措辞

## 三阶段工作流

### 阶段 1: 审查和提议 (无编辑)

每个代理:
1. 读取整个文件
2. 生成**报告**包含每个提议的更改:
   - 位置 (行号或幻灯片标题)
   - 当前文本
   - 提议修复
   - 类别 (语法/拼写错误/溢出/一致性)
3. 保存报告到 `quality_reports/` (例如 `quality_reports/LectureN_Topic_report.md`)
4. **不修改任何源文件**

### 阶段 2: 审查和批准

用户审查提议的更改:
- 全部接受、选择性接受或请求修改
- **仅在明确批准后**代理继续

### 阶段 3: 应用修复

仅应用批准的更改:
- 使用编辑工具;对多个实例问题使用 `replace_all: true`
- 验证每个编辑成功
- 报告完成摘要
